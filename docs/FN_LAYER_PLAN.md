# Слой Fn: план пресета (по раскладке A4Tech FBX50C)

Источник: раскладка Fn-ряда A4Tech FBX50C. Цель: такой же Fn-слой на Type 84.

| Сочетание | Значок на FBX50C | Предлагаемое действие (HID) |
|---|---|---|
| Fn+F1 | домик | Домашняя страница браузера (Consumer AC Home 0x0223) |
| Fn+F2 | два окна | Все окна: Ctrl+F10 (KDE «Показать все окна со всех рабочих столов»; альтернатива Meta+W — обзор) |
| Fn+F3 | стрелка назад | Назад (Consumer AC Back 0x0224) |
| Fn+F4 | лупа | Поиск (Consumer AC Search 0x0221) |
| Fn+F5 | глобус | Браузер (Consumer AL Internet Browser 0x0196) |
| Fn+F6 | фотоаппарат | Снимок всего экрана: Shift+PrintScreen (KDE Spectacle и GNOME — весь экран; PrintScreen по умолчанию открывает выбор области) |
| Fn+F7 | ⏮ | Предыдущий трек (Consumer 0x00B6) |
| Fn+F8 | ⏯ | Пауза/воспроизведение (Consumer 0x00CD) |
| Fn+F9 | ⏭ | Следующий трек (Consumer 0x00B5) |
| Fn+F10 | 🔇 | Без звука (Consumer 0x00E2) |
| Fn+F11 | 🔉 | Громкость − (Consumer 0x00EA) |
| Fn+F12 | 🔊 | Громкость + (Consumer 0x00E9) |

Решения приняты 2026-11-09 для KDE Plasma (Wayland).

Открытые вопросы:
- Fn+F2 и Fn+F6 — сочетания с модификаторами: нужна поддержка записи «клавиша + модификатор» в keymap; если её нет — макрос.
- Какие типы записей keymap (PROTOCOL.md §3.3) поддерживают consumer-коды и сочетания с модификаторами.
- Заводские Fn-сочетания (Fn+Win, Fn+End=Pause, Fn+Delete=Func 0x01) сохранить как есть.

## Статус (2026-11-09)

- Реализовано: пресет `fn-fbx50c` (`presets/fn-fbx50c.json`, секция `fn_layer`), запись SET_FN_KEY 0x26
  (`type84 preset apply fn-fbx50c`). На железе запись ещё не проверялась (UNVERIFIED).
- Дополнительно: Fn+1 / Fn+2 / Fn+3 → F13 / F14 / F15 (горячие клавиши смены режима).
- Consumer-коды пишутся записью типа 3 (`03 lo hi 00`); дескриптор клавиатуры принимает consumer 0x000–0x33C,
  так что 0x0196, 0x0221, 0x0223, 0x0224 проходят (PROTOCOL.md §1.1, §3.3).
- Сочетания с модификаторами (Fn+F2 = Ctrl+F10, Fn+F6 = Shift+PrintScreen) — одной записью KEYBOARD
  `02 mm uu 00`, где mm — битовая маска модификаторов HID (хаб так их и отображает, но сам не пишет).
  Отправляет ли прошивка модификатор — не проверено; проверить `evtest`/`wev` после записи. Макросы не нужны.
  Запасной вариант без макросов: назначить свободную клавишу (например F16) и повесить сочетание в KDE.
- Заводские Fn-сочетания (Fn+Win, Fn+End, Fn+Delete, Fn+стрелки и т. д.) не трогаются: запись функций
  производителя (FUNC) защищена, клавиша Fn (85) не переназначается.
